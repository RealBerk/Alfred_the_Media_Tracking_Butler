# Alfred Media Tracker

İzlediğiniz film ve dizileri kaydeden, sevdiklerinizi ve sevmediklerinizi
ayrı listelerde tutan, izleme listenizi yöneten ve Alfred'in size rastgele öneri sunduğu komut satırı uygulaması.

## Ne Yapar

- İzlenen film/dizi ekleme (tür, genre, başlık, yıl, yönetmen, sevme durumu)
- Sevilen ve sevilmeyen medyayı ayrı listelerde görüntüleme
- İzleme listesi oluşturma ve görüntüleme
- İzleme listesinden rastgele öneri
- Listeleri `.txt` dosyasına export etme
- Oturumlar arası kaydedileni hatirlama (JSON)
- Onaylandiginda bilgileri sifirlama

## Nasıl Çalıştırılır
- Python ile terminalden main.py'i calistirin

### Gereksinimler

- Python 3.8 veya üzeri
- Ek kütüphane gerekmez (yalnızca standart kütüphane)

### Çalıştırma

```bash
python main.py
